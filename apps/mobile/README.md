# Cassetta Mobile

Android-first Expo client for the Cassetta music library.

## Development

Start the Next.js API and Metro from the monorepo root:

```bash
pnpm --filter @cassetta/web dev
pnpm --filter @cassetta/mobile dev
```

`EXPO_PUBLIC_API_URL` in `.env` must point to the computer's LAN address so a
physical phone can reach Next.js. Copy `.env.example` when setting up another
machine.

## Android development build

Background audio and lock-screen controls use the `expo-audio` config plugin,
so use a development build for the complete experience:

```bash
pnpm --filter @cassetta/mobile android
```

Expo Go can still preview most screens, but it does not include custom native
configuration generated by this project.

## Architecture

- Expo Router for navigation
- NativeWind for the visual system
- Reacticx-inspired copy-owned animated carousel interactions
- Expo Audio for streaming, background playback, and lock-screen metadata
- Next.js `/api/mobile/*` routes for the shared MongoDB catalog and mutations
